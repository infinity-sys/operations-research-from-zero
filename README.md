# Operations Research: From Zero to Hero

Code and data for the **Operations Research: From Zero to Hero** course by Infinity Systems
(YouTube playlist: https://www.youtube.com/playlist?list=PLH7mYx2KCsXE).

For computer science and data science students first (it follows the second-year OR subject of computers
faculties in Egypt: every exam method is solved by hand, then in Python), and for engineering and business
students and anyone who makes decisions. Python basics: the Data Science course on the same channel.

- `data/`: **Nile Snacks**, the course's running case: a FICTIONAL Egyptian snack company with synthetic data
  (products, plants, warehouses, shops in Cairo, Alexandria and the Delta, costs, vans, staff needs). See `data/README.md`.
- `episodes/EXX/`: the code shown in each episode, with a short README.

Install: `pip install "pulp[cbc]" pandas` (PuLP 4 needs Python 3.12 or newer).

Prepared by Infinity Systems · www.infinitysys.org
