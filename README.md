# Operations Research: From Zero to Hero

A free course by **Infinity Systems** on YouTube. It is made for **computer science and data science students**, especially if you are taking Operations Research at university, and for anyone who makes decisions with data. You only need school math: we start from zero.

- Playlist: https://www.youtube.com/playlist?list=PLH7mYx2KCsXE
- Sister course (Python basics): Data Science: From Zero to Hero, https://www.youtube.com/playlist?list=PLDy7xS_6LZus
- Website: https://www.infinitysys.org

## How the course works
1. Each method is solved **by hand, step by step**, the way it is examined.
2. The same problem is then solved **in Python**: PuLP, SciPy, Google OR-Tools, NetworkX and SimPy.

The course covers:
- modeling
- linear programming: the graphical method, simplex, Big-M and two-phase, duality, dual simplex, sensitivity
- transportation and assignment
- network models
- integer and dynamic programming
- CPM and PERT
- nonlinear optimization and gradient descent
- decision analysis, inventory, Markov chains, queueing and simulation

## What's here
| Folder | What it holds |
|---|---|
| `data/` | The **Nile Snacks** dataset used throughout the course |
| `episodes/E01`, `E02`, … | The code shown in each episode, exactly as it ran on screen |

**About Nile Snacks:** a fictional Egyptian food company with plants, warehouses, shops and delivery vans. Its data is synthetic and made for teaching; it describes no real company.
